## Запуск

Потрібен встановлений Ruby 2.4 або новіший. Виконайте потрібну команду з кореня репозиторію:

```bash
ruby hw1/word_stats.rb
ruby hw1/guess_number.rb
ruby hw1/rock_paper_scissors.rb
```

У RubyMine відкрийте репозиторій як проєкт, виберіть інтерпретатор Ruby та запустіть потрібний файл через **Run**.

Зберігайте файли та використовуйте консоль у кодуванні **UTF-8**, щоб українські повідомлення відображалися правильно.

## 1. Статистика слів

Метод `word_stats(text)` повертає хеш зі значеннями `count`, `longest` та `unique_count`. Програма виводить ці значення в консоль.

Приклад вводу:

```text
Ruby is fun and ruby is powerful
```

Результат:

```text
Кількість слів: 7
Найдовше слово: powerful
Унікальних слів: 5
```

Слова розділяються пробілами, табуляцією або переносами рядка. Розділові знаки залишаються частиною слова. Якщо найдовших слів декілька, вибирається перше. Для порожнього рядка кількість слів дорівнює нулю, найдовшого слова немає.

## 2. Вгадай число

Метод `play_game` загадує випадкове число від 1 до 100. Після кожного припущення програма підказує «Більше!» або «Менше!». Після правильної відповіді виводить «Вгадано!» та кількість спроб.

Приймаються лише цілі числа від 1 до 100. Некоректний ввід не збільшує лічильник спроб.

## 3. Камінь, ножиці, папір

Керування цифрами:

| Ввід | Дія |
| --- | --- |
| `1` | Камінь |
| `2` | Ножиці |
| `3` | Папір |
| `0` | Вихід |

Камінь перемагає ножиці, ножиці — папір, папір — камінь. Однакові варіанти означають нічию.

Після кожного зіграного раунду виводяться перемоги користувача, перемоги комп'ютера, нічиї та загальна кількість раундів. Некоректний ввід не змінює рахунок.

Кожна програма запускається окремо; статистика гри зберігається до завершення її поточного запуску.
