# Cake Cutter 🍰

Програма на Ruby, яка розрізає «пиріг з родзинками» на прямокутні шматки так, щоб у кожному шматку була рівно одна родзинка, а всі шматки мали однакову площу.

## Умова

Пиріг задається рядком, де `.` це порожня клітинка, а `o` це родзинка:

```
........
..o.....
...o....
........
```

- Кількість шматків дорівнює кількості родзинок (від 2 до 9).
- Кожен шматок прямокутний.
- Усі шматки мають однакову площу, але форма може бути різною.
- У кожному шматку рівно одна родзинка.
- Якщо рішень кілька, обирається те, де перший шматок найширший.

## Запуск

Потрібен Ruby (перевірено на Ruby 4.0).

```bash
ruby wee.rb
```

Щоб перевірити свій торт, змініть змінну `cake` в кінці файлу:

```ruby
cake = "........\n..o.....\n...o....\n........"
puts cut(cake).join("\n\n")
```

## Приклад

Вхід:

```
........
..o.....
...o....
........
```

Вихід:

```
........
..o.....

...o....
........
```

Функція `cut` повертає масив рядків, по одному рядку на кожен шматок.

## Як це працює

1. Площа шматка = площа торта / кількість родзинок.
2. Береться перша вільна клітинка (зверху вниз, зліва направо), вона стає лівим верхнім кутом нового шматка.
3. Перебираються прямокутники потрібної площі, починаючи з найширшого. Шматок підходить, якщо він не перекривається з уже вирізаними і містить рівно одну родзинку.
4. Далі рекурсія. Якщо виникає тупик, шматок прибирається (backtracking) і пробується наступна форма.
5. Оскільки ширші варіанти перебираються першими, знайдене перше рішення має найширший перший шматок.
