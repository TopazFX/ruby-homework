# Судоку 4×4 🧩

Консольна гра «Судоку» на Ruby з полем 4×4, розділеним на чотири блоки 2×2. Без сторонніх бібліотек.

## Правила

1. У кожному рядку числа від 1 до 4 без повторень.
2. У кожному стовпці числа не повторюються.
3. У кожному блоці 2×2 числа не повторюються.
4. Початкові числа змінювати не можна.
5. Перемога настає, коли все поле заповнене правильно.

## Запуск

Потрібен Ruby.

```bash
ruby sudoku.rb
```

## Керування

Хід вводиться одним рядком: `рядок стовпець число`.

| Ввід    | Дія                                    |
|---------|----------------------------------------|
| `1 2 3` | поставити 3 у рядок 1, стовпець 2      |
| `1 2 0` | стерти свою клітинку (рядок 1, стовпець 2) |
| `q`     | вийти з гри                            |

Порожня клітинка позначається `.`.

## Приклад

```
   1 2   3 4
1  1 . | . 4
2  . 4 | 1 .
  -----------
3  2 . | . 3
4  . 3 | 2 .

Хід: 1 2 2
```

## Обробка помилок

Програма повідомляє про помилку, якщо:
- введено не три числа або є сторонні символи;
- рядок чи стовпець поза межами 1–4, або число поза межами 0–4;
- спроба змінити початкове число;
- число порушує правила (повтор у рядку, стовпці або блоці).

## Структура коду

| Метод          | Призначення                                      |
|----------------|--------------------------------------------------|
| `show`         | виводить поле в консоль                          |
| `valid_move?`  | перевіряє хід за правилами (рядок, стовпець, блок) |
| `win?`         | перевіряє перемогу                               |
| `play`         | головний цикл гри та обробка введення            |

Початкове поле зберігається в константі `START` (двовимірний масив, `0` це порожня клітинка).
